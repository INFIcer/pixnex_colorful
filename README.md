# pixnex — 色彩工具

一款桌面色彩工具，提供专业取色、实时屏幕滤镜、图像滤镜处理与对比功能。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 色彩探索 | 支持 OKLCH / HSV / CIE LCH / CIE Lab / HSI 五种色彩模型，图形化取色 + 滑块微调 |
| 屏幕取色 | 全屏覆盖取色器，放大像素网格，单击取色 |
| 实时屏幕滤镜 | 浮动窗口实时显示下方屏幕区域的滤镜效果（边缘检测、黑白、反转等） |
| 图像滤镜对比 | 拖入或粘贴图片，叠加或横向对比多种滤镜效果 |
| 软件颜色同步 | 将当前颜色与绘画软件双向同步（当前仅适配 UDM Paint，见下文说明） |

## 主窗口

- **标题栏**：自动折叠、置顶、最小化、关闭；主窗口不提供最大化按钮
- **自动折叠**：点击标题栏的「自动折叠」按钮开启后，鼠标离开主窗口即自动收起为一条标题栏，
  移入标题栏立即展开；再次点击关闭开关，若此时窗口已收起会立即展开
- **状态记忆**：自动折叠 / 置顶 / 窗口位置与尺寸自动保存到
  `%APPDATA%\pixnex_colorful\pixnex.ini`，重启后恢复上次关闭时的状态
- **紧凑布局**：8px 页边距、6px 卡片间距、8px 卡片内边距，窗口较矮时内容区滚动

### 选色
- **色彩模型**：下拉框切换五种色彩模型，切换后滑块与图形取色区同步更新，当前颜色保持不变
- **图形取色**：拖拽色相环调整色调，拖拽方形区域调整其他分量
- **滑块微调**：每个分量对应滑块 + 数字输入框，滑块背景显示渐变色条预览

### 信息面板
- **约束至 sRGB** 按钮：仅当颜色超出 sRGB 色域时**自动出现**，点击即可将颜色调整回 sRGB 色域内
- **复制 HEX**：复制16进制颜色代码到剪贴板
- **屏幕取色**：打开全屏取色器

### 屏幕滤镜
点击 **打开屏幕滤镜** 按钮，在弹窗中从两个列表里选择：左边「滤镜库」直接选一个滤镜（等于新建一个只含该滤镜的方案），右边「已保存方案」选一个之前保存好的滤镜方案，即可创建一个实时滤镜浮动窗口。方案列表下方还能**删除方案**。

### 滤镜方案（滤镜像图层一样堆叠）
一个「滤镜方案」就是若干滤镜按顺序堆叠，从第一层到最后一层依次处理得到最终效果。

- 在屏幕滤镜窗口或图像查看器里点击标题栏的**设置图标**打开**方案管理面板**
- 面板里可以：**添加滤镜**（下拉菜单）、**复制图层**、**删除图层**、**上移/下移**（也能直接在列表里拖动排序）、勾选框启用/停用某一层
- 选中某一层，右侧就是**该滤镜的参数编辑区**（原先的参数面板）
- **保存方案** 把当前方案存进方案文件；**加载方案** 载入已保存的方案
- 方案名后面的 **\*** 表示"有修改还没保存"
- 方案文件默认存在可写的用户目录（`%APPDATA%\pixnex_colorful\filter_schemes.json`，不可写时自动退回项目目录下的 `.pixnex_colorful\`），保存按钮的悬浮提示会显示实际路径

### 软件颜色同步
在主窗口的 **颜色同步** 卡片中，下拉选择要同步的软件并点击 **开启同步**。开启后，pixnex 的当前颜色与目标软件的双向同步：在任一软件中修改颜色都会同步到另一侧。

同一卡片还有 **选色后归还焦点** 勾选框（默认勾选）：开启同步后，每次**选色操作**（在色相环/方块/滑块上取色、屏幕取色、约束至 sRGB）完成时，窗口焦点会自动归还给正在同步的软件（如 CSP），可以直接继续作画。

- 拖拽选色的过程中不会抢焦点，松手后立即归还；同步软件自己改色（不是你在 pixnex 里选色）不会触发归还
- 在数值输入框里键入时不会打断，回车或点到别处后归还
- 取消勾选即可关闭该行为

卡片右上角的状态文字会说明当前同步处于哪一步：

| 状态 | 含义 |
|---|---|
| 未同步 | 未开启同步，或目标软件选了「关闭」 |
| 连接中… | 刚点击「开启同步」，第一次轮询还没结果（约 0.1 秒） |
| 已同步 | 已连上目标软件，颜色双向同步中 |
| 未启动 | **目标绘画软件还没启动**；把鼠标停在状态文字上会提示该启动哪个程序 |
| 未连接 | 软件已经在运行，但颜色数据读不到（版本不匹配、权限级别不同等） |
| 写入失败 | 读到了颜色，但把颜色推给软件时出错；tooltip 里是具体报错 |

> 「未启动」只是提示，不是错误：先打开 UDM Paint / Photoshop，状态会在约 1 秒内自动变成「已同步」，不需要重新点「开启同步」。

> ⚠️ **兼容性说明**
> - **UDM Paint**：可正常使用（内存同步；已适配其进程保护机制，需与 pixnex 使用相同权限级别运行）。
> - **Photoshop（PS）**：已按 COM + ExtendScript 适配（CC 2018 实测双向同步）。颜色读写一律通过 `DoJavaScript` 在 Photoshop 内部执行——CC 2018 的 COM 属性 `app.ForegroundColor` 返回的是本地副本，直接改 `rgb.Red` 不会真正改到 Photoshop，读到的也可能是旧快照（这就是之前「显示已同步但读写都没同步」的原因）。首次连接若弹出「是否允许运行脚本」，允许即可。
> - **Photoshop 绿色版**：走 CEP 脚本桥（隐藏面板）。部署后需要重启 Photoshop 才会加载；面板没有心跳时状态会显示「未连接」并提示重启，不会假装已同步。
> - **其他软件**：暂未适配。
> - **进程检测**：同步子系统一律使用 `colorPickerPro/sync/win_process.py` 的原生进程快照，**不得 import psutil**（导入会让 UDM Paint 的进程保护永久拒绝 pixnex 的内存访问）。

## 实时屏幕滤镜窗口

浮动窗口实时显示其下方屏幕区域的滤镜效果。

| 操作 | 效果 |
|---|---|
| 双击标题栏 / 按空格键 | 折叠窗口（仅保留标题栏），再次操作展开 |
| 暂停 / 继续（标题栏图标） | 暂停或恢复实时捕获 |
| 设置（标题栏图标） | 打开或关闭滤镜方案管理面板（图层管理 + 被选滤镜的参数） |

### 滤镜参数

部分滤镜可调节参数，包括数值滑块、开关、颜色选择器。某些参数关联主开关，主开关关闭时相关参数自动禁用。

## 界面架构

应用采用一套自建的轻量设计系统，主窗口、对话框与无边框滤镜窗口全部复用同一套样式：

- **设计令牌**：`colorPickerPro/ui/tokens.py` 定义调色板、间距、圆角、字号与语义角色（`Role` / `State` / `Variant`）。
- **全局样式表**：`colorPickerPro/ui/stylesheet.py` 由令牌生成，`colorPickerPro/ui/theme.py` 的 `apply_theme(app)` 一次性装载 Fusion 调色板、字体、中文翻译与 QSS。业务代码不再写 `setStyleSheet`。
- **组件库**：`colorPickerPro/ui/components/` 提供标题/说明/状态标签、主次/危险/幽灵/图标按钮、卡片、分隔线、颜色块、滚动区、自动换行 `FlowLayout`、自绘无框对话框/消息框/文件选择器等。复杂控件（取色盘、滑块组、参数编辑器、滤镜方案面板、图像查看器）都由这些基础控件组合而成。
- **响应式约定**：只用 Qt 布局管理器；窗口缩小时内容用滚动区或 `FlowLayout` 换行，不硬编码控件尺寸；图形取色器随容器宽度自适应缩放并居中；列表/参数分栏用 `QSplitter` 并设置最小宽度。
- **窗口风格**：主窗口、全部对话框、滤镜方案面板、图像对比窗口与屏幕滤镜窗口都使用同一套自绘标题栏与 1px 方角边框，不显示系统标题栏；四边/四角均可拖动缩放；文件选择、消息框、输入框也使用自绘无框窗口。
- **图标资源**：所有界面图标均为 SVG 资产，位于 `colorPickerPro/ui/assets/icons/`，由 `tools/gen_ui_assets.py` 生成，打包时由 `pixnex.spec` 一并收集（含 QtSvg 运行库）。应用图标（`pixnex.ico`）是另一套多尺寸位图，见下文「应用图标」。
- **文案**：界面文字保持简短、正式；不使用 emoji、字符图标或口语化长句。

新增或改造界面时，请先阅读 [`docs/UI_ARCHITECTURE.md`](docs/UI_ARCHITECTURE.md)（含组件速查、编码铁律与跨文件 API 约定）。

## 应用图标

`pixnex.ico` 是应用身份的唯一来源，同时用于三处：

| 用途 | 位置 |
|---|---|
| 主窗口标题栏图标（16×16） | `TitleBar` 左侧，由 `init_frameless(icon=...)` 传入 |
| 窗口 / 任务栏 / Alt-Tab 图标 | `QApplication.setWindowIcon(app_icon())` |
| 打包后 `pixnex.exe` 的文件图标 | `pixnex.spec` 中 `EXE(icon='pixnex.ico')` |

图标是**用代码画的**，不要手工改位图：改设计就改 `tools/gen_app_icon.py`（深色圆角底板 + 色相环 + 中心取色块），然后重新生成：

```powershell
.venv\Scripts\python.exe tools\gen_app_icon.py            # 重新生成 pixnex.ico
.venv\Scripts\python.exe tools\gen_app_icon.py --preview  # 额外输出 build\icon-preview 预览图
```

生成脚本一次写入 16/20/24/28/32/40/48/64/128/256 共 10 个尺寸（覆盖 Windows 100%–250% 缩放），
小尺寸会加粗色环、放大中心色块以保证标题栏和任务栏里可辨认。打包时 `pixnex.spec` 会把同一份
`pixnex.ico` 既嵌进 EXE 资源、又作为数据文件带进产物，供运行时加载窗口图标。

## 打包

```
build.bat                     # 一键打包，产物 dist\pixnex.exe（单文件）
```

使用 **onefile（单文件）** 模式：产物就是 `dist\pixnex.exe` 一个文件。引导程序每次启动都要先把整包解压到 `%TEMP%\_MEIxxxxxx`（退出时自动清理），所以首次启动比 onedir 慢 1~2 秒；如果系统临时目录不可写或被安全软件拦截，会在任何 Python 代码运行前弹出 `Could not create temporary directory!`，此时把 `pixnex.spec` 末尾 EXE 的 `runtime_tmpdir=None` 改成 `runtime_tmpdir='.'`（解压到 exe 所在目录）或一个确定可写的绝对路径即可。

分发时只拷 `dist\pixnex.exe` 这一个文件。

## 图像滤镜对比窗口

### 打开方式
在主窗口下方拖放区域**拖入**图片，或鼠标悬浮在区域时 **Ctrl+V 粘贴**图片。拖放区只作为入口，不显示载入的图片。

### 布局模式

| 模式 | 说明 |
|---|---|
| 重叠对比 | 多个滤镜结果堆叠，顶部导航按钮悬停预览，单击永久切换；每个视图独立记忆缩放状态 |

## 常见问题

**折叠的窗口无法再展开？**
再次双击标题栏或按空格键即可展开。

**主窗口开启自动折叠后只剩标题栏？**
鼠标移入标题栏即可恢复；点击标题栏的自动折叠按钮可关闭该行为，关闭后窗口会立即展开。

**屏幕滤镜窗口卡顿？**
窗口会自动调节性能。如果仍感觉卡顿，可点击暂停图标暂停捕获，或缩小窗口面积。

**取色器启动后屏幕没有变化？**
移动鼠标即可看到十字准星和放大面板。

**色彩模型切换后颜色变了？**
不同色彩模型的取值范围不同，切换后颜色值会自动转换，视觉上应保持一致。

**同步状态显示「未连接 / 写入失败」怎么办？**
把鼠标停在状态文字上看 tooltip：它会说明是「没启动」「没有打开的文档」「脚本桥没有心跳」还是具体的 COM 报错。Photoshop 走 COM 时两个程序要以相同权限级别运行（都普通启动，或都以管理员启动）。

**如何重置图像查看器到初始状态？**
点击「适应」按钮恢复默认缩放，或使用「复位」按钮重置旋转。
