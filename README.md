# pixnex — 色彩工具

一款桌面色彩工具，提供专业取色、实时屏幕滤镜、图像滤镜处理与对比功能。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 色彩探索 | 支持 OKLCH / HSV / CIE LCH / CIE Lab / HSI 五种色彩模型，图形化取色 + 滑块微调 |
| 屏幕取色 | 全屏覆盖取色器，放大像素网格，单击取色 |
| 实时屏幕滤镜 | 浮动窗口实时显示下方屏幕区域的滤镜效果（边缘检测、黑白、反转等） |
| 图像滤镜对比 | 拖入或粘贴图片，叠加或横向对比多种滤镜效果 |
| 软件颜色同步 | 将当前颜色与绘画软件双向同步（当前仅适配 UDM Paint，见下文说明） |

## 主窗口

### 选色
- **色彩模型**：下拉框切换五种色彩模型，切换后滑块与图形取色区同步更新，当前颜色保持不变
- **图形取色**：拖拽色相环调整色调，拖拽方形区域调整其他分量
- **滑块微调**：每个分量对应滑块 + 数字输入框，滑块背景显示渐变色条预览

### 信息面板
- **约束至 sRGB** 按钮：仅当颜色超出 sRGB 色域时**自动出现**，点击即可将颜色调整回 sRGB 色域内
- **📋 复制 HEX**：复制16进制颜色代码到剪贴板
- **🎯 屏幕取色**：打开全屏取色器

### 屏幕滤镜
点击 **🎨 屏幕滤镜** 按钮，在弹窗中从两个列表里选择：左边「滤镜库」直接选一个滤镜（等于新建一个只含该滤镜的方案），右边「已保存方案」选一个之前保存好的滤镜方案，即可创建一个实时滤镜浮动窗口。方案列表下方还能**删除方案**。

### 滤镜方案（滤镜像图层一样堆叠）
一个「滤镜方案」就是若干滤镜按顺序堆叠，从第一层到最后一层依次处理得到最终效果。

- 在屏幕滤镜窗口或图像查看器里点击 **⚙** 打开**方案管理面板**
- 面板里可以：**＋添加滤镜**（下拉菜单）、**⧉复制图层**、**✕删除图层**、**▲上移/▼下移**（也能直接在列表里拖动排序）、勾选框启用/停用某一层
- 选中某一层，右侧就是**该滤镜的参数编辑区**（原先的参数面板）
- **💾保存方案** 把当前方案存进方案文件；**📂加载方案** 载入已保存的方案
- 方案名后面的 **\*** 表示"有修改还没保存"
- 方案文件默认存在可写的用户目录（`%APPDATA%\pixnex_colorful\filter_schemes.json`，不可写时自动退回项目目录下的 `.pixnex_colorful\`），保存按钮的悬浮提示会显示实际路径

### 软件颜色同步
在主窗口的 **🎨 颜色同步** 行中，下拉选择要同步的软件并点击 **开启同步**。开启后，pixnex 的当前颜色与目标软件的双向同步：在任一软件中修改颜色都会同步到另一侧。

同一行还有 **归还焦点** 勾选框（默认勾选）：开启同步后，每次**选色操作**（在色相环/方块/滑块上取色、屏幕取色、约束至 sRGB）完成时，窗口焦点会自动归还给正在同步的软件（如 CSP），可以直接继续作画。

- 拖拽选色的过程中不会抢焦点，松手后立即归还；同步软件自己改色（不是你在 pixnex 里选色）不会触发归还
- 在数值输入框里键入时不会打断，回车或点到别处后归还
- 取消勾选即可关闭该行为

> ⚠️ **兼容性说明**
> - **UDM Paint**：可正常使用（内存同步）。
> - **Photoshop（PS）**：版本存在问题，当前不可用（绿色版需部署脚本桥并重启 PS 后生效，注册版 COM 依赖权限一致，存在稳定性问题）。
> - **其他软件**：暂未适配。

## 实时屏幕滤镜窗口

浮动窗口实时显示其下方屏幕区域的滤镜效果。

| 操作 | 效果 |
|---|---|
| 双击标题栏 / 按空格键 | 折叠窗口（仅保留标题栏），再次操作展开 |
| **⏸** / **▶** | 暂停或恢复实时捕获 |
| **⚙** | 打开或关闭滤镜方案管理面板（图层管理 + 被选滤镜的参数） |

### 滤镜参数

部分滤镜可调节参数，包括数值滑块、开关、颜色选择器。某些参数关联主开关，主开关关闭时相关参数自动禁用。

## 打包

```
build.bat                     # 一键打包，产物 dist\pixnex\pixnex.exe
```

使用 **onedir** 模式（不是 onefile）：onefile 的引导程序启动时要先把整包解压到 `%TEMP%\_MEIxxxxxx`，一旦系统临时目录不可写或被安全软件拦截，就会在任何 Python 代码运行前弹出 `Could not create temporary directory!`。onedir 直接从目录运行，不依赖临时目录，启动也更快。

分发时请把整个 `dist\pixnex\` 文件夹一起拷贝（不是只拷 exe）。

## 图像滤镜对比窗口

### 打开方式
在主窗口下方拖放区域**拖入**图片，或鼠标悬浮在区域时 **Ctrl+V 粘贴**图片。

### 布局模式

| 模式 | 说明 |
|---|---|
| 重叠对比 | 多个滤镜结果堆叠，顶部导航按钮悬停预览，单击永久切换；每个视图独立记忆缩放状态 |
| 横向对比 | 并排显示，所有视图同步平移、缩放、旋转 |

> 已知问题：横向对比模式下缩放窗口会导致图像偏移。

## 常见问题

**折叠的窗口无法再展开？**
再次双击标题栏或按空格键即可展开。

**屏幕滤镜窗口卡顿？**
窗口会自动调节性能。如果仍感觉卡顿，可点击 ⏸ 暂停捕获，或缩小窗口面积。

**取色器启动后屏幕没有变化？**
移动鼠标即可看到十字准星和放大面板。

**色彩模型切换后颜色变了？**
不同色彩模型的取值范围不同，切换后颜色值会自动转换，视觉上应保持一致。

**如何重置图像查看器到初始状态？**
点击「适应」按钮恢复默认缩放，或使用「复位」按钮重置旋转。
